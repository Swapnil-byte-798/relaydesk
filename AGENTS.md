# Project rules

The owner explicitly requested that this portfolio project use skills from their resume. Python and SQL are the implementation languages. Do not add JavaScript, TypeScript, HTML/CSS development, React, Next.js, or other custom web frontend work unless the owner explicitly requests it.

Use Python, FastAPI, SQLAlchemy, SQL, pytest, Docker, Git/GitHub, CI/CD, and LLM APIs where they solve an actual requirement. Keep specialist-agent orchestration in readable Python. Do not add a framework outside the owner's resume just for hosting convenience. The interactive surfaces are a Python CLI and automatically generated FastAPI API documentation.

Keep financial policy in code, require a human approval before recording any sandbox refund, scope every order lookup to the customer, and prevent duplicate actions in the database. Label demo records and sandbox actions honestly. Do not claim live LLM verification without actually calling the configured provider.

Push completed, reviewable milestones to the owner's GitHub repository. Keep credentials, customer data, runtime state, and local environments out of Git.
